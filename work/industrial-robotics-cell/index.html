What I did

  • Camera-based visual servoing
  • ROS 2 interface via RoboDK driver and KUKA RSI for real-time motion correction
Read the full story

A dual-arm KUKA cell for dexterous assembly and metal forming. The arms work with several end effectors, including suction, parallel and point tools, and switch between them with tool changers.

I commissioned the entire cell myself: the tools and tool changers, the safety systems with SICK scanners and light curtains, and the cameras used for visual servoing.

For control I developed a ROS 2 interface using the RoboDK driver together with the KUKA RSI communication interface, which gives real-time motion regulation and superposition on top of the planned paths.
